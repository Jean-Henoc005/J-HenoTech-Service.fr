# HenoTech Services — Votre informatique, notre solution.

Bienvenue sur le dépôt de mon portfolio personnel **J-HenoTech**. Ce site présente mon profil d'étudiant en BTS CIEL, mes compétences, mes projets, mon parcours, et les services informatiques que je propose.

🔎 **Je recherche une alternance ou un stage** pour compléter mon année de BTS CIEL (2026/2027).

## 🚀 Présentation

J-HenoTech est un site statique (HTML, CSS, JavaScript, sans framework) qui réunit :

- un **portfolio** pour les recruteurs et les entreprises ;
- une **page de services** pour les particuliers, indépendants et petites entreprises (création de site web, installation de Windows).

Il est responsive : ordinateur, tablette et smartphone.

## ✨ Fonctionnalités

- 🏠 Accueil avec photo de profil et accès au CV (PDF)

## ⚙️ Installation et utilisation

**Méthode 1 : ouvrir le site directement**

1. Téléchargez le projet ou clonez le dépôt :
   ```bash
   git clone https://github.com/Jean-Henoc005/<nom-du-depot>.git
   ```
2. Ouvrez le dossier du projet.
3. Lancez `index.html` dans votre navigateur.

**Méthode 2 : Visual Studio Code**

1. Ouvrez le dossier dans Visual Studio Code.
2. Installez l'extension **Live Server** si nécessaire.
3. Clic droit sur `index.html` → **Open with Live Server**.

## 🎨 Personnalisation

| Fichier | Rôle |
|---|---|
| `index.html` | Contenu du portfolio (guide de modification en commentaire à la fin du fichier) |
| `services.html` | Présentation des services |
| `style.css` | Couleurs, animations ; section « PHOTOS DE FOND » en haut pour changer une photo et régler le voile |
| `script.js` | Menu, dock, apparitions au défilement, agrandissement des images |
| `images/` | Logo, photos et illustrations |

La palette (fond ardoise, une seule couleur d'accent) se règle dans `:root` au début de `style.css`.
